# Reflexión Final del Proyecto

## Aprendizajes Principales
El desarrollo de este proyecto me permitió comprender de forma práctica la importancia del control de versiones con Git y GitHub en entornos colaborativos. Los aspectos clave aprendidos fueron:

1. **Gestión de Ramas:** Mantener la rama principal protegida y utilizar ramas secundarias para proponer cambios de forma segura sin afectar la versión estable.
2. **Flujo de Trabajo Colaborativo:** Coordinar aportes con un compañero mediante Pull Requests, lo cual facilita la revisión de código antes de la integración.
3. **Resolución de Conflictos:** Identificar y resolver diferencias (Merge Conflicts) cuando dos colaboradores modifican la misma línea de texto, integrando la versión final de manera consciente.

## Conclusión
El uso adecuado de herramientas como Git y GitHub optimiza la comunicación en equipo, garantiza la trazabilidad del trabajo mediante commits descriptivos y evita la pérdida o sobreescritura accidental de la información.
