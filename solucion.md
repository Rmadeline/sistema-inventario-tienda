# Solución Tecnológica del Inventario

## Concepto
Diseño conceptual de un sistema digital de gestión de inventario para tiendas de barrio, accesible desde dispositivos móviles y de escritorio.

## Módulos Principales
* Registro de productos: Alta de productos con nombre, categoría, precio de compra, precio de venta y stock inicial.
* Entradas y salidas: Módulo para actualizar el inventario con nuevas compras o registrar las ventas del día.
* Alertas de stock mínimo: Notificaciones automáticas cuando un producto esté por agotarse.
* Reportes básicos: Resumen diario de ventas y productos con mayor rotación.
