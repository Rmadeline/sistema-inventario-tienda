# Requisitos Principales y Priorización

## Requisitos Funcionales
1. **RF-01:** Registrar, editar y eliminar productos del catálogo (Prioridad: ALTA).
2. **RF-02:** Registrar entradas y salidas de stock en tiempo real (Prioridad: ALTA).
3. **RF-03:** Generar alertas visuales cuando un producto alcance el stock mínimo (Prioridad: MEDIA).
4. **RF-04:** Generar reporte diario de inventario y ventas (Prioridad: MEDIA).

## Requisitos No Funcionales
1. **RNF-01:** Interfaz amigable e intuitiva para rápida adaptación del usuario (Prioridad: ALTA).
2. **RNF-02:** Disponibilidad del sistema para consulta continua en horarios de atención (Prioridad: ALTA).
