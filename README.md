# sistema-inventario-tienda
Proyecto conceptual para la gestión y control de inventario de tienda local.
### Sobre el proyecto
Este repositorio contiene la documentación completa y el modelado de requerimientos para un **Sistema de Inventario para Tiendas de Barrio**.

### Contenido del Repositorio
En los archivos Markdown de este proyecto encontrarás:
* **`problema.md`**: Diagnóstico de la problemática en tiendas locales.
* **`solución.md`**: Propuesta de software para el control de entradas, salidas y alertas.
* **`requisitos.md`**: Requerimientos del sistema priorizados.
* **`planificación.md`**, **`colaboración.md`** y **`reflexión.md`**: Gestión de tareas, flujo de trabajo en equipo e integración con Git y GitHub.
